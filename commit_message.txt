## How It Works

```
Data Collection → Tokenization → Processing → Training → Evaluation → Serving
```

1. **Collect Data**: Gather text from web, code repositories, books
2. **Tokenize**: Convert text to token IDs
3. **Process**: Clean, split, prepare for training
4. **Train**: Train transformer model on GPU
5. **Evaluate**: Test performance on validation set
6. **Serve**: Deploy model via API
